## 背景

經銷商登入後可依自身的廠別與胎種別，下載對應的店招合約書範本 PDF。合約書清單由建大後台人員自行維護上載。

## 前台

- 依登入帳號的**國家 + 胎種別**自動篩選，只顯示該帳號適用的合約書
- 廠別、胎種別不顯示在畫面上（帳號已設定，自動過濾）
- 顯示欄位：店級別、更新日期、檔名、下載連結
- 點擊即可下載 PDF

## 後台維護

| 欄位 | 說明 |
|---|---|
| 廠別 | 給建大自行維護（KD、KF…），不帶到前台 |
| 胎種別 | 給建大自行維護（PCR、BC、MC…），不帶到前台 |
| 店級別 | 形象店／特約服務中心／一般店 |
| 上載資料 | PDF 檔案 |
| 更新日期 | 程式依上載當天自動填入 |

後台功能：上載、刪除、下載、修改

## 權限

- 各廠商企：只能維護**自己廠**的資料
- 總公司商企：最大權限，可維護所有廠
