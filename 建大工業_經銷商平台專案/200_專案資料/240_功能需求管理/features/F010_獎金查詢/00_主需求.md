# 【F010】獎金查詢 — 主需求

- **功能編號**：F010
- **功能名稱**：經銷商獎金查詢
- **提出人／日期**：客戶原始需求（見 `230_內部專案檔案\建大工業_需求進度執行_20260617_已驗核_backup.pptx` 投影片 39-40）
- **狀態**：本機修改完成（**2026-07-20 由 AI 對照程式碼補登記，尚未經本機測試／客戶驗收**，見風險評估表）

## 背景

主要經銷商需要查看自己與同群組下線經銷商的當期獎金，邏輯與 F009 業績查詢相同，但 ERP 只回傳最終獎金數字，不傳細部明細（設計原則，避免爭議時無法追溯）。

## 主需求描述

API：`GET /api/kenda/bonus`（`controllers/finance.py`），依 `ym` 篩選；透過 `erp_client.query_bonus()` 取 ERP 結算後獎金數字；`KendaBonus` model 暫存；支援主帳號＋下線查詢，邏輯同 F009。

## 驗收標準

- [ ] 本機測試：`ym` 篩選正確、主帳號可查群組下線資料
- [ ] 客戶測試端同步部署
- [ ] 客戶驗收

## 已知風險／待確認

- ERP 僅回傳最終獎金數字、不傳明細——若經銷商對金額有疑義，目前只能靠業務人工說明，平台無法提供明細佐證。
- 獎金結算邏輯完全在 ERP 端，正確性依賴 ERP 端 `/bonus` API 介接進度。
