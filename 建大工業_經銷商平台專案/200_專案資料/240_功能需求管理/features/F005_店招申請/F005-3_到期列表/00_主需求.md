# 【F005-3】到期列表 — 主需求

- **功能編號**：F005-3
- **功能名稱**：到期列表
- **父功能**：F005 店招申請
- **提出人／日期**：建大工業，內容來源 `220_客戶提供資料\店招相關\店招畫面.pptx`
- **狀態**：已接受需求

## 背景

經銷商可查詢自身名下所有店招的合約到期資訊，資料由建大後台人員透過 Excel 上載維護。

## 前台

**查詢條件**（擇一）：
- 車行名稱
- 廣告編號
- 經銷商
- 合約到期日區間（起始日～結束日）

支援模糊搜尋。

**顯示欄位**：廣告編號、車行名稱、業主名稱、電話、地址、申請項目、合約到期日

**其他**：
- 每頁 10 筆，超出可按下一頁
- 可下載查詢結果為 PDF
- 只顯示**自己帳號**的資料，不可跨經銷商查詢
- 依登入帳號國家篩選，**絕對不可跨國查詢**

## 後台資料來源

- 與 F005-4 進度查詢**共用同一份 Excel 表**（`廣告資產.xlsx`）
- 後台人員上載 Excel → 前台撈取對應國家、對應經銷商客代的最新版本顯示

## 驗收標準

- [ ] 可用車行名稱、廣告編號、經銷商、到期日區間查詢
- [ ] 支援模糊搜尋
- [ ] 每頁 10 筆，有分頁功能
- [ ] 可下載查詢結果 PDF
- [ ] 只顯示自己帳號資料，不可跨經銷商、不可跨國
