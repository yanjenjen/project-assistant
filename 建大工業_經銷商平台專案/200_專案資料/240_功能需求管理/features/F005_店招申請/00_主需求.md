# 【F005】店招申請 — 主需求

- **功能編號**：F005
- **功能名稱**：店招申請
- **提出人／日期**：建大工業，內容來源 `220_客戶提供資料\店招相關\店招畫面.pptx` + 2026-07-01 會議補充
- **狀態**：已接受需求

## 背景

經銷商透過入口網站辦理店招相關業務，包含提出申請、下載合約書範本、查詢申請進度與合約到期資訊。

## 整體架構

> **2026-07-13 更正**：前端頂層導覽「店招申請」（`H.SIGNAGE`）與「合約下載」（`H.CONTRACTS`）是**兩個平行的獨立選單項**，合約下載**不是**店招申請底下的分頁，已改編號為 F006、搬到頂層 `F006_合約下載\`。
>
> **2026-07-16 更正**：原規劃 4 個內部分頁的 F005-2（合約/狀態）與 F005-4（進度查詢）合併為單一分頁，維持「進度查詢」名稱。「店招申請」頁面內部實際只剩 3 個分頁：申請書／進度查詢（合併後，車行/狀態/申請進度/合約起訖日/申請項目/更新日期）／到期列表，下表已更正對應。

```
店招申請（H.SIGNAGE，前端 3 個內部分頁）
├── 申請書     F005-1  經銷商填寫店招申請表單（新增、維修、作廢移招）
├── 進度查詢   F005-2  合併原「合約(狀態)」+ 原F005-4「進度查詢」，查詢申請案狀態/進度/合約起訖日
└── 到期列表   F005-3  查詢合約到期資訊，可下載 PDF

合約下載（H.CONTRACTS，獨立頂層頁面，與店招申請平行）
└── F006  依帳號國家＋胎種別下載對應合約書範本 PDF
```

## 共用規則（4個分頁皆適用）

- 只顯示**自己帳號**的資料，不可跨經銷商查詢
- 依**登入帳號國家**篩選，不可跨國查詢
- 合約到期前 **6 個月** Odoo 自動寄 mail 提醒

## 資料來源總覽

| 分頁 | 資料來源 |
|---|---|
| 申請書 | 經銷商即時填寫送出 |
| 進度查詢（合併後，見 `F005-2_進度查詢\00_主需求.md`） | `kenda.signage` model，跟申請書同一份申請記錄，欄位子集顯示 |
| 到期列表 | 後台人員維護 Excel 上載（共用廣告資產.xlsx） |
| 合約下載（F006，獨立頁面） | 後台人員手動上載 PDF |
