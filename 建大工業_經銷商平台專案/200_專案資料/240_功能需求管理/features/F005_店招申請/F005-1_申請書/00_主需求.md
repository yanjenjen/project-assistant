# 【F005-1】申請書 — 主需求

- **功能編號**：F005-1
- **功能名稱**：申請書
- **父功能**：F005 店招申請
- **提出人／日期**：建大工業，內容來源 `220_客戶提供資料\店招相關\店招畫面.pptx` + 2026-07-01 會議補充
- **狀態**：已接受需求

## 背景

經銷商透過入口網站提出店招製作申請（新增、維修、作廢移招）。申請送出後進入建大 BPM 簽核流程，由建大資訊負責後續產出廣告編號與申請書 PDF，不在艾創點範圍。

## 前台表單欄位

| 欄位 | 規則 |
|---|---|
| 申請人 | 依登入帳號自動帶出，**不可手填** |
| 國家 | 依登入帳號自動帶出，**不可手填** |
| 廣告物縣市 | 下拉選單，依登入帳號國家篩選省縣市 |
| 廣告物編號 | 條件顯示（見下方邏輯說明） |
| 車行名稱、聯絡人、電話、住址 | 自填；廣告物編號空白時由申請人手動填寫，有歷史資料時自動帶入 |
| 施工項目大項 | 後台維護清單帶出，可勾選（見後台維護） |
| 施工項目細項 | 依先前 PPT 設定的等級分類，支援自填 |
| 合約書起訖日 | 自填 |

## 廣告物編號核心邏輯

- 施工項目選「**新增**」→ 廣告物編號帶出**空白**（新申請尚無編號）
- 施工項目選「**維修 / 作廢移招**」→ 申請者輸入廣告編號 → 系統帶出歷史資料預填表單
  - 帶出後送出 = 複製舊資料存成新一筆申請，舊資料不動
- 廣告物編號作廢欄為「Y」→ **前台不可勾選送出**（該編號已作廢）
- 同一廣告編號 BPM **未結案**時 → 平台不可重複提出第二筆

> 廣告編號定義：建大事後給予廣告物的識別代號（非系統送出即產生），用於後續維修聯絡。

## 特殊邏輯

- 「續約、盤點、作廢資產轉移」目前不在前台，後台預留開關供未來彈性開放

## 後台維護（艾創點負責）

1. **施工項目維護**：總公司商企可新增／修改，集團同步，維護後才出現在前台
2. **廣告物縣市維護**：國別＋省縣市清單，集團同步，支援 Excel 上下載

## 不在艾創點範圍

- 廣告編號產生 → 建大資訊 BPM
- 申請書 PDF 下載 → 建大資訊
- 工作委託單 → 建大業務

## 驗收標準

- [ ] 申請人、國家依登入帳號自動帶出且不可修改
- [ ] 廣告物縣市為下拉選單，依登入帳號國家篩選
- [ ] 施工項目選「新增」時廣告物編號為空白
- [ ] 施工項目選「維修／作廢移招」時可輸入廣告編號帶出歷史資料
- [ ] 作廢廣告編號（Y）無法勾選施工項目送出
- [ ] 同一廣告編號 BPM 未結案時，平台擋掉重複提出
- [ ] 施工項目大項、細項等級分類顯示正確，支援自填
- [ ] 合約書起訖日欄位存在
- [ ] 後台施工項目可維護
- [ ] 後台廣告物縣市可維護，支援 Excel 上下載
