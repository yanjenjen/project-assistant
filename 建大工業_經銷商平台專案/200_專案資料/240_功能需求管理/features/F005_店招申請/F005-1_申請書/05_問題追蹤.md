## 2026-07-01 — 廣告編號回傳機制（待確認）

**狀態**：待確認

**問題**：
廣告編號由建大資訊 BPM 在審核簽核完成後才產出，艾創點 Odoo 平台本身沒有這個資料。

目前有兩個待確認點：

1. **申請書送出後，Odoo 這邊有沒有存一份申請資料？**
   - 有存 → 可以做「輸入廣告編號帶出歷史資料」功能，資料來源是 Odoo 自己
   - 沒存 → 資料只在 BPM，Odoo 查不到

2. **BPM 核准後，廣告編號有沒有回傳給 Odoo？**
   - 有回傳 → 才能讓經銷商在申請書輸入舊編號查到舊資料
   - 沒回傳 → 這個功能做不了，除非另外開 API 串接

**待辦**：確認合約是否包含 BPM 回傳廣告編號給 Odoo 的機制。
