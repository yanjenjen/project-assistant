## 執行結果摘要

**現況診斷（執行前）**：
- `kenda.announcement` 原已有 `product_category`（單選）欄位，對應主需求「適用產品類別」
- `kenda.dealer` 已有 `product_category_ids`（多選，Many2many → kenda.product.category）
- 發現既有 bug：`controllers/content.py` 的前台過濾邏輯讀取 `dealer.product_category`（單數），但客戶主檔上只有 `product_category_ids`（複數），導致「依產品類別過濾」實際上從未生效
- 客戶主檔匯入腳本 `import-data/convert_new.py` 的 SRC 寫死 0612 版路徑（非記憶原先以為的 0608 版），且是最後一次實際執行匯入所用的版本（2026-06-15）

2. `stack/odoo/addons/kenda_platform/views/kenda_announcement_views.xml`：list/form 改用 `widget="many2many_tags"` 呈現
3. `stack/odoo/addons/kenda_platform/controllers/content.py`：修正前台 `/announcements` 過濾邏輯，改用 `dealer.product_category_ids` 與 `announcement.target_category_ids` 交集比對（消息未設顯示對象＝所有人可見；沿用原邏輯）
4. 前台 JS bundle：`index-BnEs5qT0.v9.js` → 複製為 `v10.js`，把兩處 `product_category` 渲染改成 `target_categories`（陣列 join 顯示），`index.html` 改指向 v10（無原始碼可改，僅能直接修補打包後的 bundle）
