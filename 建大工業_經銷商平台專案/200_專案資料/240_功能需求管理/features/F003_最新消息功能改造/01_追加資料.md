**問題2：✅ 已修復——公告圖片前台顯示 placeholder（圖示裂圖），已部署** 根因：公告圖片原本用 Odoo 原生 `/web/image/kenda.announcement/<id>/image` 路由讀取，該路由要求登入 Odoo 網頁 session 才有讀取權限；前台是匿名瀏覽器直接讀圖片網址（用自訂 API token 系統，非 Odoo session），被 ACL 擋下，圖檔本身、附件記錄、實體檔案都正常存在，只是讀取權限被擋，Odoo 靜默回傳預設 placeholder 圖。修法：新增公開路由 `GET /api/kenda/announcements/<id>/image`（`controllers/content.py`，`auth='public'`，用 `sudo()` + `ir.binary._get_image_stream_from` 讀取），`image_url` 改指向新路由。本機、遠端都已驗證：匿名請求可直接拿到真實圖片（本機 JPEG 1024x240、遠端同張圖 227KB），不再是 placeholder。
