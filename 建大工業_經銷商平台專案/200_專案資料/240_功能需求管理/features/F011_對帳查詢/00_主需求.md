# 【F011】對帳查詢 — 主需求

- **功能編號**：F011
- **功能名稱**：經銷商對帳查詢
- **提出人／日期**：客戶原始需求（見 `230_內部專案檔案\建大工業_需求進度執行_20260617_已驗核_backup.pptx` 投影片 41-42）
- **狀態**：本機修改完成（**2026-07-20 由 AI 對照程式碼補登記，尚未經本機測試／客戶驗收**，見風險評估表）

## 背景

主要經銷商需要查看自己與同群組下線經銷商的對帳彙總（對帳金額／當期發票／當期折讓），邏輯與 F009／F010 相同，ERP 只回傳彙總結果。

## 主需求描述

API：`GET /api/kenda/reconciliation`（`controllers/finance.py`），依 `ym` 篩選；透過 `erp_client.query_reconciliation()` 取對帳彙總；`KendaReconciliation` model 暫存；回傳 `recon_amount`（對帳金額）、`period_invoice`（當期發票）、`period_allowance`（當期折讓）；支援主帳號＋下線查詢。

## 驗收標準

- [ ] 本機測試：`ym` 篩選正確、三個彙總數字正確
- [ ] 客戶測試端同步部署
- [ ] 客戶驗收

## 已知風險／待確認

- ERP 僅回傳彙總結果，不含逐張發票明細——若未來需要明細下鑽，需另開發功能與對應 ERP API。
- 對帳邏輯完全在 ERP 端，正確性依賴 ERP 端 `/reconciliation` API 介接進度。
