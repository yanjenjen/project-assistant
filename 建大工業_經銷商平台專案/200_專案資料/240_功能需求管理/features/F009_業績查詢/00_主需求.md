# 【F009】業績查詢 — 主需求

- **功能編號**：F009
- **功能名稱**：經銷商業績查詢
- **提出人／日期**：客戶原始需求（見 `230_內部專案檔案\建大工業_需求進度執行_20260617_已驗核_backup.pptx` 投影片 37-38）
- **狀態**：本機修改完成（**2026-07-20 由 AI 對照程式碼補登記，尚未經本機測試／客戶驗收**，見風險評估表）

## 背景

主要經銷商需要查看自己與同群組下線經銷商的當期業績明細與總計，資料由 ERP 結算後回傳最終數字，平台不自行運算。

## 主需求描述

API：`GET /api/kenda/performance`（`controllers/finance.py`），依 `ym`（年月）篩選；透過 `erp_client.query_performance()` 取 ERP 結算後總額；`KendaPerformance` model 暫存同步資料；回傳 `own`（自己）／`group`（下線）／`total`（合計）三層彙總；群組關係由 `parent_dealer_id` 欄位決定——若經銷商未設定「經銷商代碼」則僅能查看自己資料。

## 驗收標準

- [ ] 本機測試：`ym` 篩選正確、own/group/total 三層彙總數字正確
- [ ] 本機測試：無 `parent_dealer_id` 的帳號只能看自己資料（權限隔離）
- [ ] 客戶測試端同步部署
- [ ] 客戶驗收

## 已知風險／待確認

- 業績結算邏輯完全在 ERP 端，正確性依賴 ERP 端 `/performance` API 是否已如期完成介接，需跟建大 ERP 團隊核對進度。
- `parent_dealer_id` 群組關係目前由後台設定，維護流程／權責待確認。
