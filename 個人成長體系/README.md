# 個人成長作業系統（PGOS）

本資料夾是個人長期成長的正式單一資料來源，納入 Git 版本管理。對話僅用於分析與協作；正式策略、盤點、證據、案例及檢討均應回存於此。

## 快速開始

1. 閱讀 `00_系統說明與戰略/個人成長體系手冊_2026_V1.0.docx`。
2. 開啟 `01_成長管理中心/個人成長管理中心_2026_V1.0.xlsx`，先填「成長戰略」與「能力盤點」。
3. 在「12週計畫」只選 1 項核心能力、1 個實戰專案及 1 項資產成果。
4. 平日只維護本週行動與成果證據；每週、每月、每季依固定節奏檢討。

## 管理原則

- 以職涯定位決定學習，不追逐熱門工具。
- 以實戰專案帶動學習，課程只是支援。
- 能力必須由真實成果、外部回饋或可重複方法證明。
- 每季最多主動發展 1 項核心能力及 1–2 項支援能力。
- 每次工作至少沉澱案例、方法、模板或 AI 工作流其中一項。
- 週管理不超過 20 分鐘、月管理不超過 60 分鐘、季管理不超過 3 小時。

## 資料安全

- 案例進入 Git 前必須去識別化，不放客戶名稱、帳號、個資、密碼或商業機密。
- 大型附件及機密原始檔只存放安全位置；本系統保存索引、摘要與去識別化證據。
