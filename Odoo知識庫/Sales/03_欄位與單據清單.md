## 二、狀態流（Status Flow）

### 報價/訂單主流程
```
Draft（草稿/Quotation）
  → Quotation Sent（報價已寄送）
  → Sales Order（確認後，Confirm）
  → [Cancelled 取消（客戶 Reject）]
```
（來源 SAL04/07）

### 出貨狀態
```
Ready（就緒）→ Done（完成，Validate 後）
```
（來源 SAL02/25）

### 發票狀態
```
Draft（草稿）→ Confirmed（已確認，Confirm）→ Paid（已付款，綠色 Paid banner）
```
（來源 SAL01/02）

### 商機（CRM，SAL15）
```
Lead → Opportunity（Convert）→ Proposition → Won
```

### 佣金計畫（SAL28）
```
Draft → Approved（Approve）→ [Reset to Draft]
```

### 運送方式（SAL23）
```
Unpublished（紅）→ Published（綠）
```

### 產品發布（SAL08）
```
Unpublished（紅 Go to website）→ Published（綠）
```
