- Settings 設定頁面是唯一需要手動儲存的頁面
- 頂部工具列的圖示依安裝模組不同而有所差異
- Smart Button 數量與類型依關聯模組與記錄而異

## Getting Started 核心操作欄位（2026-07-15）

> 來源：Create an Odoo Database + Filters and Views + Multi-Company Basics + Multi-Company Transactions

### 資料庫建立欄位

| 欄位 | 中英對照 | 說明 |
|------|---------|------|
| Company Name | 公司名稱 | 建立資料庫時的公司名，自動成為資料庫 URL |
| Country | 國家 | 決定財務本地化套件，建立後不可更改 |
| Company Size | 公司規模 | 下拉選單（少於 5 人 / 5-50 / 50+ 等） |
| Primary Interest | 主要用途 | 如 Teaching / Selling Products 等 |

### 使用者管理欄位

| 欄位 | 中英對照 | 說明 |
|------|---------|------|
| Access Rights | 存取權限 | 各 App 的使用者等級（無 / 使用者 / 管理員） |
| Allowed Companies | 允許的公司 | 多公司設定下，使用者可操作的公司清單 |
| Notification Style | 通知方式 | Handle by Emails 以郵件 / in Odoo 系統內通知 |
| Digital Signature | 數位簽名 | 使用者自行設定的電子簽名圖樣 |

### 多公司欄位

| 欄位 | 中英對照 | 說明 |
|------|---------|------|
| Fiscal Localization Package | 財務本地化套件 | Settings → Accounting → 決定科目表，第一筆日記帳後欄位消失 |
| Currency | 幣別 | 公司記帳幣別，第一筆交易後永久鎖定 |
| Company (on product) | 產品公司欄位 | 空白=所有公司可見，指定=限該公司 |

### 跨公司交易欄位

| 欄位 | 中英對照 | 說明 |
|------|---------|------|

## 權限與聯絡人標籤章節欄位清單（2026-07-24）

> 來源：demo 環境（v19-ce-jenny）開發者模式實際操作核對

### 聯絡人標籤欄位（res.partner.category）

| 中文名稱 | 英文名稱 | 位置 | 說明 |
|---------|---------|------|------|
| 名稱 | Name | 聯絡人標籤設定 | 標籤顯示文字 |
| 類別 | Category (Parent Category) | 聯絡人標籤設定 | 選填，指向另一筆標籤作為上層分類，僅一層，畫面顯示為「上層 / 子標籤」 |
| 顏色 | Color | 聯絡人標籤設定 | 系統色板約 11 色 + 無色，純視覺辨識用途 |
| 標籤 | Tags (category_id) | 聯絡人表單主畫面 | many2many，可複選，可直接輸入新建 |

### 權限技術層欄位（ir.model.access / ir.rule）

| 中文名稱 | 英文名稱 | 位置 | 說明 |
|---------|---------|------|------|
| 名稱 | Name | 存取權 Access Rights 清單 | 這筆存取規則的識別名稱 |
| 模型 | Model | 存取權 / 記錄規則清單 | 對應的資料模型（如 sale.order） |
| 組 | Group | 存取權清單 | 適用的使用者群組 |
| 讀取 / 寫入存取 / 建立存取 / 刪除存取 | Read / Write / Create / Unlink | 存取權清單 | 模型層級的 CRUD 總開關 |
| 群組 (無群組 = 一般) | Groups (No group = Global) | 記錄規則表單 | 適用群組；留空代表全域套用 |
| 規則定義（範圍篩選） | Rule Definition (Domain) | 記錄規則表單 | Domain 條件式，決定能看到哪些具體記錄 |
| 啟用 | Active | 記錄規則表單 | 關閉則此規則暫停生效 |
