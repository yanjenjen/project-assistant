## 模組定位

Getting Started 不是業務模組，而是 **Odoo 介面基礎操作** 的學習章節。  
任何導入 Odoo 的企業，所有使用者都需要先掌握這些操作。

---

## 適用情境

適用情境：
- 企業首次導入 Odoo，新使用者上線教育訓練
- 顧問 Demo 前的環境導覽說明
- IT 管理員設定使用者帳號、語言、2FA

不適用情境：
- 業務功能操作（請見各模組 SOP）

## 權限與聯絡人標籤深化章節（2026-07-24）

> 來源：demo 環境（v19-ce-jenny）開發者模式實際操作核對 + Odoo 19 官方文件
> 定位：補足前期知識庫缺口——聯絡人標籤（分類工具）與權限卡控的技術落地層（Access Rights + Record Rules），並依產業情境說明「為什麼要建置」，對應本階段知識庫「補足知識庫＋建檔 SOP 化」的目標

| 功能 | 中英對照 | 說明 |
|------|---------|------|
| 聯絡人標籤 | Contact Tags | 聯絡人分類/篩選工具（res.partner.category），支援一層階層與顏色標記，不具權限功能 |
| 存取權 | Access Rights | 模型層級 CRUD 總開關（ir.model.access），決定群組能不能用某個功能 |
| 記錄規則 | Record Rules | 記錄層級 domain 篩選（ir.rule），決定看得到哪些具體資料，與存取權疊加運作 |

## Getting Started 核心操作章節功能清單（2026-07-15）

> 來源：Create an Odoo Database + Filters and Views + Multi-Company Basics + Multi-Company Transactions（4 支影片）

| 功能 | 中英對照 | 說明 |
|------|---------|------|
| 資料庫建立 | Create Database | odoo.com → Start Now Free → 選 App → 填公司資料 → 啟動 |
| 啟用連結 | Activation Email | 建立後 3 小時內需點啟用連結，否則資料全部刪除 |
| 公司資訊設定 | Company Info | Settings → Companies → Update Info：Logo / 地址 / 電話 / 網站 |
| 新增使用者 | Add User | Settings → Users → New：姓名 / Email / 存取權限 / 偏好設定 |
| 使用者邀請信 | Invitation Email | 建立後自動寄送，讓使用者自行設定密碼與數位簽名 |
| 安裝 App | Install Apps | 主頁 Apps 搜尋 → Install（需管理員權限） |
| Demo 資料 | Demo Data | Settings → Developer Mode → Load Demo Data（勿用於正式資料庫） |
| 搜尋篩選器 | Search Filters | 搜尋列右側下拉 → 依條件篩選（日期 / 業務員 / 類型） |
| 自訂篩選 | Custom Filters | 布林條件組合，可堆疊多層 |
| 儲存為預設 | Save as Default | 篩選 → 收藏夾 Favorites → 設定為預設 Default Filter |
| 看板視圖 | Kanban View | 依欄位分欄顯示，支援拖曳變更負責人 |
| 日曆視圖 | Calendar View | 依日期顯示記錄，點擊快速預覽 |
| 樞紐分析 | Pivot View | 交叉統計表，可選 Measures，支援插入試算表 |
| 圖表視圖 | Graph View | 圓餅 / 折線 / 長條圖，可插入試算表 |
| 活動視圖 | Activity View | 橫軸=活動類型，縱軸=單據編號，紅=逾期，綠=未來 |
| 多公司管理 | Multi-Company | Settings → Companies → Manage Companies：獨立稅務實體 |
| 公司切換 | Company Picker | 右上角公司選單，可同時啟用多家（當前以高亮標示） |
| 財務本地化套件 | Fiscal Localization | Settings → Accounting → Package：決定科目表與稅務 |
| 使用者允許公司 | Allowed Companies | 使用者設定 → Multi-Company 區塊：控制可見公司範圍 |
| 跨公司交易 | Intercompany Transactions | Settings → Companies → Intercompany Transactions → 啟用 |
| 跨公司日記帳 | Intercompany Journal | 買方採購日記帳 / 賣方銷售日記帳各自獨立 |
| 公司別價格表 | Company Pricelist | Sales → Products → Pricelists：依公司設定幣別價格表 |
