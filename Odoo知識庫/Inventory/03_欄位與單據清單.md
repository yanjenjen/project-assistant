# Odoo Inventory 模組 - 欄位與單據清單

> 模組：Inventory（庫存）
> 版本標示：Odoo 17（依影片介面與功能推測，待確認）
> 學習日期：2026-07-30
> 狀態：草稿
> 資料來源：37 支官方教學影片（INV01–INV37）

---

## 一、主要單據類型

### 1. Receipt（收貨單）
**定義**：從廠商或退貨客戶接收產品的入庫單據。由確認 Purchase Order 自動建立，或手動建立（寄售品、退貨）。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Source Document | 來源 PO 編號；追蹤此收貨對應哪張採購訂單 |
| Receive From | 供應商名稱 |
| Assigned Owner | 寄售品的所有人（廠商）；設定後庫存估值為 $0 |
| Destination Location | 收貨後商品存放的目標儲位 |
| Scheduled Date | 預計到貨日期 |
| Operations Tab → Demand | 訂購數量（來自 PO）|
| Operations Tab → Quantity | 實際到貨並驗收的數量 |
| Lot/Serial Number | 批號或序號（需啟用 Traceability） |
| Package | 貨物所在的包裝容器 |
| Packages Smart Button | 收貨後建立的包裹清單 |
| Move Smart Button | 顯示此收貨的庫存移動明細（From → To） |
| Traceability Smart Button | 顯示批號/序號的完整追蹤路徑 |

---

### 2. Delivery Order（出貨單）
**定義**：將產品從倉庫出貨至客戶的單據。由確認 Sales Order 自動建立。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Source Document | 來源 SO 編號 |
| Delivery Address | 客戶收貨地址 |
| Source Location | 揀貨來源儲位（預設 WH/Stock） |
| Destination Location | 出貨目的地（預設 Customers） |
| Scheduled Date | 承諾出貨日期（影響 Before Scheduled Date 保留方式） |
| Deadline | 最終出貨期限（客戶前置時間計算） |
| Product Availability | 綠色 = 全部可用；黃色 = 有庫存但未保留；日期 = 預計到貨日 |
| Operations Tab → Demand | 客戶訂購數量 |
| Operations Tab → Quantity | 已保留/可出貨數量 |
| Operations Tab → Lot/Serial | 已指派的批號或序號 |
| Additional Info → Shipping Method | 承運商 / 出貨方式 |
| Additional Info → Shipping Information | 顯示承運商詳情（如 FedEx） |
| Returns Type（Operation Type 層級） | 指定退貨使用的作業類型 |
| Back Order Smart Button | 連結至部分出貨後建立的補發單 |
| Chatter | 出貨標籤 PDF 自動出現於此 |

---

### 3. Internal Transfer（內部移轉單）
**定義**：在倉庫內部不同儲位之間移動商品的單據。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Operation Type | 移轉作業類型（Internal Transfer / Pick / Pack） |
| Source Location | 起始儲位 |
| Destination Location | 目標儲位 |
| Operations Tab → Product | 移轉的產品 |
| Operations Tab → Demand | 計畫移轉數量 |
| Packages Tab → Add a Line | 以整個 Package 為單位移轉 |
| Mark as To-Do | 確認移轉計畫（不立即驗收） |
| Put in Pack | 將選定產品打包至新 Package |

---

### 4. Inventory Adjustment / Physical Inventory（庫存調整 / 實地盤點）
**定義**：記錄系統帳面庫存與實際盤點數量差異的調整單據。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Product | 盤點產品 |
| Location | 盤點儲位 |
| Lot/Serial Number | 批號或序號（如啟用） |
| On Hand Quantity | 系統在手數量（調整前） |
| Counted Quantity | 實際盤點數量（手動填入） |
| Difference | 系統自動計算差異量 |
| Scheduled Date | 下次循環盤點預定日期 |
| Assigned To | 循環盤點負責人 |
| Last Count Date | 上次盤點日期 |

---

### 5. Landed Cost（落地成本單）
**定義**：將採購附加費用（運費、關稅等）分攤至收貨產品的成本單。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Vendor Bill | 對應的廠商帳單 |
| Transfers | 關聯的已驗收收貨單（只能選已 Validate 的 Receipt） |
| Product | 落地成本產品（Service 類型） |
| Split Method | 成本分攤方法 |
| Account | 費用入帳科目 |
| Valuation Adjustments Tab → Additional Cost | 各產品分攤到的落地成本 |
| Valuation Adjustments Tab → Original Value | 收貨時的原始成本 |
| Valuation Adjustments Tab → New Value | 加上落地成本後的新成本 |

---

### 6. Batch Transfer（批次移轉）
**定義**：將多張揀貨單或出貨單合併為一次執行的作業單。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Responsible | 負責執行此批次的人員 |
| Operation Type | 批次類型（Pick / Delivery） |
| Vehicle | 指派的配送車輛（DMS 功能） |
| Current Weight / Volume | 批次目前的重量/體積使用量 |
| Max Weight / Volume | 車輛容量上限 |
| Transfers Tab | 此批次包含的所有移轉單 |
| Detailed Operations Tab | 所有產品、數量、來源/目標儲位明細 |
| Map Button | 顯示客戶地址地圖（DMS 啟用後） |

---

### 7. Wave Transfer（波次移轉）
**定義**：依倉庫區域（Location）分組的揀貨批次，適合大型倉庫分區作業。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Responsible | 負責此波次的揀貨員 |
| Transfers | 此波次包含的揀貨單 |
| Detailed Operations Tab | 同 Batch Transfer，顯示各產品位置 |

---

### 8. Reordering Rule（補貨規則）
**定義**：設定自動或手動觸發補貨的規則。

| 欄位名稱 | 業務意義 |
|---------|---------|
| Product | 適用產品 |
| Location | 監控的儲位（預設 WH/Stock） |
| Route | 補貨路線（Buy / 倉庫間補貨路線） |
| Min Quantity | 最小庫存量（低於此值時觸發） |
| Max Quantity | 目標補貨至此數量 |
| Multiple Quantity | 數量倍數（如最小訂購量） |
| Forecasted Quantity | 預測數量（在手 + 確認進貨 - 確認出貨） |
| Trigger | Auto（排程器每日自動觸發）或 Manual（手動 Order） |
| Suggested Quantity | Odoo 自動計算的建議補貨量（Max - Forecasted） |

## 二、重要主檔欄位

### Product（產品主檔）

| 欄位 / 位置 | 業務意義 |
|-----------|---------|
| Product Type | Goods（實物可追蹤）/ Service（服務不入庫）/ Consumable（消耗品不追蹤） |
| Track Inventory（Goods 類型下） | 勾選 = 追蹤庫存數量；不勾 = 不追蹤（如耗材） |
| Tracking | By Quantity / By Lots / By Unique Serial Number |
| Purchase Checkbox（表頭） | 勾選 = 可採購，會顯示 Purchase Tab |
| Routes（Inventory Tab） | 指定此產品適用的路線（Buy / MTO / Manufacture / 倉庫補貨路線） |
| Customer Lead Time（Inventory Tab）| 向客戶承諾的出貨前置時間（天數） |
| Expiration Date / Best Before / Removal Date / Alert Date（Inventory Tab） | 易腐品到期日計算基礎（天數，從到貨日起算） |
| Weight（Inventory Tab → Logistics）| 產品重量（用於出貨標籤與 DMS 車輛容量計算） |
| Unit of Measure | 庫存計量單位（主單位） |
| Purchase UoM（Purchase Tab → Vendors） | 向廠商採購使用的計量單位（可不同於庫存單位） |
| Barcode | 產品條碼（供 Barcode App 掃描） |
| Product Category | 決定適用的成本法、移除策略、稅務等 |
| Cost | 產品成本（用於庫存評估） |
| Sales Tab → Packagings | 銷售包裝規格（如 Fat Quarter、Six-Pack） |

---

### Location（儲位主檔）

| 欄位 | 業務意義 |
|-----|---------|
| Location Name | 儲位名稱（Closest Location 策略依此排序） |
| Parent Location | 上層儲位（形成樹狀階層） |
| Location Type | Internal（倉庫內）/ Customer / Transit / Production / Inventory Loss |
| Barcode（Additional Info）| 儲位條碼（供 Barcode App 掃描） |
| Removal Strategy（Logistics）| 此儲位適用的移除策略（FIFO/LIFO/FEFO/Closest/Least Packages） |
| Inventory Frequency（Cyclic Counting）| 循環盤點間隔天數 |
| Storage Category | 指定此儲位屬於哪個儲存類別（用於 Putaway Rules 與容量管理） |
| Is a Dock Location | 勾選後此儲位可作為 DMS 裝卸碼頭 |
| Scrap Loss Account（Inventory Loss 類型）| 報廢品計入的會計科目 |

---

### Lot / Serial Number（批號 / 序號主檔）

| 欄位 | 業務意義 |
|-----|---------|
| Lot/Serial Number | 批號或序號代碼 |
| Product | 所屬產品 |
| Created On | 建立日期（即到貨日期，FIFO/LIFO 依此排序） |
| Expiration Date | 此批次的到期日 |
| Best Before Date | 最佳賞味期限日 |
| Removal Date | 應從庫存移除的日期（FEFO 依此排序） |
| Alert Date | 觸發提醒活動的日期 |
| Traceability Smart Button | 此批號的完整移動路徑 |
| Location Smart Button | 此批號目前所在儲位 |

---

### Package（包裹主檔）

| 欄位 | 業務意義 |
|-----|---------|
| Package Name | ODoo 自動產生的包裹編號（如 PACK00000019） |
| Package Use | Reusable Box（可重複使用）/ Disposable Box（一次性） |
| Location | 包裹目前所在儲位 |
| Contents | 包裹內的產品清單與數量 |
| Package Transfer Smart Button | 此包裹的所有移動歷史 |

---

### Operation Type（作業類型主檔）

| 欄位 | 業務意義 |
|-----|---------|
| Operation Type | Receipt / Delivery / Internal Transfer / Manufacturing / Returns 等 |
| Sequence Prefix | 單據編號前綴（如 WH/IN、WH/OUT、RE） |
| Default Source Location | 預設來源儲位 |
| Default Destination Location | 預設目標儲位 |
| Reservation Method | At Confirmation / Manual / Before Scheduled Date |
| Returns Type | 退貨時使用的作業類型（Delivery Orders 設定） |
| Move Entire Packages | 勾選後移轉時以整個 Package 為單位 |
| Automatic Batches | 自動建立批次（可依 Carrier / Employee 分組） |

---

## 三、Unit of Measure 與 Packaging 欄位

### Unit of Measure（計量單位）

| 欄位 | 業務意義 |
|-----|---------|
| UoM Name | 計量單位名稱（如 yd、m、kg） |
| Category | UoM 所屬類別（僅同類別可自動換算） |
| Reference Unit | 此類別的基準單位（Contains = 1） |
| Contains（Ratio）| 此 UoM 等於幾個基準單位（計算公式：此 UoM ÷ 基準單位） |

### Packaging（銷售/採購包裝規格）

| 欄位 | 業務意義 |
|-----|---------|
| Packaging Name | 包裝規格名稱（如 Fat Quarter、Bolt、Six-Pack） |
| Contained Quantity | 此包裝含幾個基本 UoM 單位 |
| Reference UoM | 此包裝所依據的計量單位 |
