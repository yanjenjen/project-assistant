## 每次學習 Session 標準流程

1. 觀看影片（Odoo 官方 YouTube 為主，80%；其他來源 20%）
2. AI 工具轉錄逐字稿
3. 貼入 Cowork，由海瑟姆萃取操作步驟與欄位
4. Jenny 確認內容，補充實際 demo 環境差異
5. 寫出 Track A（本知識庫）+ Track B（Notion 個人學習版）
6. 在 demo 環境實際操作驗證，截圖補充

## 知識庫使用說明

本知識庫為 **Track A — 內部顧問知識庫**，供 AI 員工在以下情境引用：

- 顧問訪談前的模組功能確認
- 客戶疑難排解時的參考依據
- 系統規劃時的功能對應查詢
- Demo 環境情境腳本設計
- 教學操作文件產出

各模組資料夾結構一致：
```
[模組]/
  01_功能概覽.md        ← 模組定位、業務場景、主要功能
  02_操作SOP.md         ← 逐步操作流程（學習後填入）
  03_欄位與單據清單.md   ← 畫面欄位說明（學習後填入）
  04_內控點與風險.md     ← 顧問視角的控制點與風險
  05_Demo情境腳本.md    ← 示範場景與操作路徑
  06_常見問題.md        ← FAQ 與疑難排解
```
