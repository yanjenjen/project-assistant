# Odoo Purchase 模組 - 欄位與單據清單

> 版本標示：Odoo 17（依影片介面與功能推測，待確認）
> 學習日期：2026-07-22
> 狀態：🔄 草稿
> 說明：依單據類型整理欄位，來源標注影片代碼

---

## 一、單據類型彙總

| 單據 | 英文名 | 建立時機 | 對應影片 |
|------|--------|---------|---------|
| 詢價單 | Request for Quotation (RFQ) | 手動新建 / 補貨規則自動產生 | PAL01–PAL10 |
| 採購單 | Purchase Order (PO) | 確認 RFQ 後轉換 | PAL01 |
| 收貨單 | Receipt | PO 確認後自動產生 | PAL01 |
| 廠商帳單 | Vendor Bill | 手動從 PO 建立（依帳單政策） | PAL07 |
| 框架訂單 | Blanket Order | 手動建立長期協議 | PAL06 |
| 採購範本 | Purchase Template | 手動建立重複採購範本 | PAL09 |

## 二、RFQ / Purchase Order 欄位

### 表頭欄位

| 欄位名稱 | 說明 | 必填 | 影片參考 |
|---------|------|------|---------|
| Vendor（廠商） | 供應商，帶入廠商主檔資訊 | ✅ | PAL01 |
| Vendor Reference（廠商參考號） | 廠商端單號（對帳用） | — | — |
| Order Deadline（訂單截止日） | 廠商需在此日前確認的期限 | 建議填 | PAL01, PAL02 |
| Expected Arrival（預計到貨日） | 系統依前置時間自動計算；可手動調整 | — | PAL02, PAL08 |
| Source Document（來源文件） | 觸發此 PO 的來源（如銷售訂單編號） | — | PAL03 |
| Ask Confirmation（詢問確認） | 是否要求廠商於入口網站確認 | — | — |
| Purchase Representative（採購負責人） | 負責此訂單的採購人員 | — | — |
| Company（公司） | 多公司環境下的公司別 | — | — |
| Currency（幣別） | 採購幣別 | — | — |

### Products 分頁欄位

| 欄位名稱 | 說明 | 影片參考 |
|---------|------|---------|
| Product（產品） | 採購品項 | PAL01 |
| Description（說明） | 產品描述（可編輯） | — |
| Quantity（數量） | 採購數量；補貨規則自動計算 | PAL01, PAL03 |
| UoM（計量單位） | 單位 | — |
| Unit Price（單價） | 廠商報價；廠商價格表自動帶入 | PAL01, PAL04 |
| Taxes（稅） | 採購稅 | — |
| Discount（折扣 %） | 廠商數量折扣（需啟用 Discount 欄位） | PAL04 |
| Analytic Account（分析帳號） | 費用歸屬分析 | — |
| Scheduled Date（排程日期） | 預計到貨日（行項層級） | PAL08 |
| Tax Excluded Subtotal（未稅小計） | 數量 × 折扣後單價 | PAL04 |

### Other Information 分頁欄位（PO）

| 欄位名稱 | 說明 | 影片參考 |
|---------|------|---------|
| Billing Status | 帳單狀態（Nothing to Bill / Waiting Bills / Fully Billed） | PAL07 |
| Incoterm | 貿易條件 | — |
| Payment Terms | 付款條件 | — |
| Fiscal Position | 財政狀況（稅率對應） | — |

### 狀態流轉

```
RFQ（草稿）
  → RFQ Sent（已發送 Email）
  → [To Approve]（需審核，金額超過門檻）
  → Purchase Order（已確認）
```

|---------|------|---------|

| Ordered（已訂購量） | 各品項累計已下 PO 數量 | PAL06 |
| Billed（已開票量） | 各品項累計已建帳單數量 | PAL06 |

| 欄位名稱 | 說明 | 影片參考 |
|---------|------|---------|
| Vendor | 廠商 | PAL04 |
| Vendor Product Name | 廠商端產品名稱（對帳用） | — |
| Vendor Product Code | 廠商端產品編號 | — |
| Delivery Lead Time | 廠商交貨前置天數（= Vendor Lead Time） | PAL02, PAL04 |
| Price（單價） | 廠商報價 | PAL04 |

| Start Date / End Date | 此價格有效期間 | — |
| Currency | 報價幣別 | — |

| 欄位名稱 | 說明 | 影片參考 |
|---------|------|---------|
| Product | 補貨品項 | PAL03 |
| Location | 倉庫位置 | PAL03 |
| Route | 補貨路徑（Buy / Manufacture 等） | — |
| Min Quantity（最小庫存） | 低於此值觸發補貨 | PAL03 |

## 九、系統設定相關欄位

路徑：Purchase → Configuration → Settings

| 設定欄位 | 類型 | 說明 | 影片參考 |
|---------|------|------|---------|
| Purchase Order Approval | 核取方塊 | 啟用採購審核流程 | PAL05 |
| Minimum Amount（審核門檻） | 金額 | 超過金額需主管審核 | PAL05 |
| Warnings | 核取方塊 | 啟用廠商/產品警告功能 | PAL05 |
| Purchase Agreements | 核取方塊 | 啟用框架訂單 & 採購範本 | PAL06, PAL09 |
| Purchase Alternatives | 核取方塊 | 啟用替代詢價（比價）功能 | PAL08 |
| Bill Control（全域政策） | 下拉 | Ordered / Received Quantities | PAL07 |
| 3-Way Matching | 核取方塊 | 啟用三方比對（付款前確認收貨） | PAL07 |
| Security Lead Time for Purchase | 天數 | 採購安全緩衝天數（全公司） | PAL02 |
| Days to Purchase | 天數 | 廠商審核 RFQ 所需天數 | PAL02 |
