## 一、Lead 表單欄位

| 欄位名稱 | 說明 | 備註 |
|---------|------|------|
| Lead Name（名稱） | Lead 的標題 | 必填 |
| Probability（成交機率）| AI 自動計算的成交可能性 % | 可手動覆蓋；設 100% 無法轉換 |
| AI 按鈕 | 查看 AI 評分依據 | 機率旁的齒輪圖示 |
| Contact Name | 聯絡人姓名 | |
| Company Name | 公司名稱 | 轉 Opportunity 時必填 |
| Email | 聯絡 Email | Lead Enrichment 的起點 |
| Phone | 電話 | |
| Salesperson | 負責業務人員 | |
| Sales Team | 負責銷售團隊 | |
| Source | Lead 來源（UTM） | 行銷歸因報表使用 |
| Campaign | 行銷活動（UTM） | 行銷歸因報表使用 |
| Tags | 標籤（可多個） | 用於篩選與報表 |

**Lead 特有操作按鈕**：
- **Convert to Opportunity**：轉為商機
- **Mark as Lost**：標記遺失
- **Enrich**：Lead Enrichment（需 IAP）

---

## 二、Opportunity（商機）表單欄位

| 欄位名稱 | 說明 | 備註 |
|---------|------|------|
| Title（名稱） | 商機標題 | 必填 |
| Expected Revenue（預期營收） | 預計成交金額 | |
| Expected Closing（預計收盤日） | 預計成交日期 | |
| Probability（成交機率） | AI 計算 + 可手動改 | 齒輪圖示 = 還原 AI 值 |
| Priority（優先度） | ⭐ ~ ⭐⭐⭐（1–3 星） | 業務一眼識別重要度 |
| Tags（標籤） | 分類標籤，可多個 | 如：Product, Furniture, Tables |
| Salesperson（業務人員） | 負責業務 | |
| Sales Team（銷售團隊） | 負責團隊 | |
| Company | 客戶公司 | |
| Contact | 聯絡人 | |
| Stage（階段） | 當前 Pipeline 階段 | 拖拉或頂部 Status Bar 移動 |
| Internal Notes（內部備註） | 業務內部筆記 | 不對外顯示 |
| Lost Reason | 遺失原因（Lost 時填） | 可自訂選項 |
| Closing Note | 遺失詳細說明 | 可選填 |

**Information Tab 額外欄位**：
- Contact Information（地址等）
- Marketing 來源追蹤（UTM Source / Medium / Campaign）

**商機操作按鈕**：
- **Won**：標記成交
- **Lost**：標記遺失
- **Restore**（Lost 後顯示）：還原商機
- **Enrich**：補全公司資訊（IAP）

## 三、Activity 欄位

| 欄位名稱 | 說明 |
|---------|------|
| Activity Type | 活動類型（Call / Meeting / Email / To-Do / Document / 自訂） |
| Summary | 活動標題/摘要（顯示在 Pipeline 卡片） |
| Due Date | 到期日 |
| Assigned To | 負責人（可與商機負責人不同） |
| Notes | 活動詳細說明 |

**Activity Type 設定欄位**：

| 欄位 | 說明 |
|------|------|
| Name | 活動類型名稱 |
| Action | 觸發動作（Phone Call / Meeting / Upload Document / None） |
| Dashboard Visibility | Own Activities / All Activities |
| Default User | 預設負責人（空白 = 商機負責人） |
| Default Summary | 預設摘要 |
| Schedule | N 天後（基於完成日或期限日） |
| Keep Done | 勾選 = 已完成活動保留在視圖 |
| Default Notes | 預設說明文字 |
| Chaining Type | Suggest Next / Trigger Next |
| Suggest / Trigger | 下一個活動類型 |
| Email Template | 搭配活動的 Email 模板 |

---

## 四、Activity Plan 欄位

| 欄位 | 說明 |
|------|------|
| Plan Name | 計畫名稱 |
| Activity Type | 活動類型（每行） |
| Summary | 本計畫的自訂摘要 |
| Assignment | Ask at Launch / Default User |
| Interval / Unit | 時間間隔（天/週/月） |
| Trigger | Before plan date / After plan date |

---

## 五、Sales Team（銷售團隊）欄位

| 欄位 | 說明 |
|------|------|
| Team Name | 團隊名稱 |
| Team Leader | 團隊主管 |
| Email Alias | 專屬 Email（發信自動建立商機） |
| Accept Emails From | Everyone / Authenticated Partners / Followers / Authenticated Employees |
| Company | 所屬公司 |
| Invoicing Target | 月度業績目標（需 Sales App） |
| Assignment Rules | Domain 篩選條件（多條件可搭配 AND/OR） |
| Skip Auto Assignment | 勾選 = 不接受自動指派（個別業務設定） |

## 六、Lead Mining 設定欄位

| 欄位 | 說明 |
|------|------|
| Generate | Companies / Companies and Contacts |
| Country | 目標國家 |
| State | 目標州/省（如適用） |
| Industries | 產業分類 |
| Filter on Size | 員工人數範圍 |
| Role | 聯絡人職能（僅 Companies and Contacts 模式） |
| Seniority | 層級（Manager / Executive 等） |
| Sales Team | 指派至哪個團隊 |
| Salesperson | 指派至哪位業務 |
| Default Tags | 自動附加標籤 |

---

## 七、Gamification 欄位

| 欄位 | 說明 |
|------|------|
| Goal Definition Name | 目標定義名稱 |
| Computation Mode | Count of Records（數量）/ Sum（金額）/ Progression（進度） |
| Challenge Name | 挑戰名稱 |
| Who（User Filter） | 指定挑戰對象（Sales Team Members / 個別業務） |
| Periodicity | Monthly / Weekly / Yearly / Once |
| Start / End Date | 挑戰期間 |
| Display Mode | Individual Goals / Leaderboard |
| Target | 數值目標（如 $20,000） |
| Badge | 徽章（完成後獎勵） |
| Report Frequency | 通知頻率（Weekly / Monthly） |

## 八、主要單據/頁面清單

| 單據/頁面 | 位置 | 用途 |
|---------|------|------|
| Lead 清單 | CRM → Leads | 管理所有潛在客戶 |
| Pipeline（Kanban） | CRM → 主畫面 | 商機管理看板 |
| 商機表單 | Pipeline → 點選商機 | 商機詳細資訊 |
| Activity Types | CRM → Configuration → Activity Types | 管理活動類型 |
| Activity Plans | CRM → Configuration → Activity Plans | 管理活動計畫 |
| Sales Teams | CRM → Configuration → Sales Teams | 管理銷售團隊 |
| Settings | CRM → Configuration → Settings | CRM 系統設定 |
| Activities Report | CRM → Reporting → Activities | 活動完成報表 |
| Sales Team Dashboard | Sales → Teams | 銷售團隊績效摘要 |
| Pipeline Report | CRM → Reporting → Pipeline | 商機分析 |
| Lead Generation Rules | Events → Configuration → Lead Generation | 活動報名 Lead 規則 |
| Visits to Leads Rules | CRM → Configuration → Visits to Leads | 網站訪客 Lead 規則 |
| Goal Definitions | Settings → Gamification Tools → Goal Definitions | 遊戲化目標定義 |
| Challenges | Settings → Gamification Tools → Challenges | 遊戲化挑戰管理 |
| Badges | Settings → Gamification Tools → Badges | 徽章管理 |
