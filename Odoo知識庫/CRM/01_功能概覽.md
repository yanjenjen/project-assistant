## 一、模組定位

**解決的問題**：集中管理業務商機與客戶跟進，避免商機散落在各人信箱或筆記本；自動化活動排程、智慧評分、團隊指派，讓業務團隊聚焦在最有可能成交的商機。

**適用對象**：業務人員（日常跟進）、業務主管（Pipeline 監控）、行銷人員（Lead 來源分析）、Sales Operations（流程自動化設定）

**在 Odoo 中的位置**：主選單 → CRM App；Sales → My Pipeline / Teams

## 二、主要功能區塊

| 功能區塊 | 說明 | 對應畫面入口 |
|---------|------|------------|
| Pipeline 管理 | Kanban 看板，拖拉移動商機階段，顏色指標反映活動狀態 | CRM → 主畫面 |
| Lead / Opportunity 管理 | Lead 建立、轉換為 Opportunity、設定預期金額與收盤日 | CRM → Leads / Pipeline |
| Won / Lost 追蹤 | 標記成交或遺失，記錄原因，可還原遺失商機 | 商機表單右上 Won/Lost 按鈕 |
| Activity 管理 | 排程電話、會議、Email、待辦、文件等活動 | 商機卡片時鐘圖示 |
| 自訂 Activity | 建立符合業務流程的自訂活動類型，設定串連觸發 | CRM → Configuration → Activity Types |
| Activity Plan | 一鍵套用預設活動計畫，自動展開多個串連活動 | CRM → Configuration → Activity Plans |
| 預測成交率 | AI 根據歷史資料自動計算每個商機的成交機率 | 商機表單 Probability 欄位 |
| 銷售團隊管理 | 多團隊設定、規則式自動分配商機 | Configuration → Sales Teams |
| Lead 生成 - 網站表單 | 網站聯絡表單直接建立 Lead/Opportunity | Website App + CRM 整合 |
| Lead 生成 - 活動/預約/訪客 | 活動報名、線上預約、網站訪客自動轉 Lead | Events/Website App + CRM |
| Lead 擴充（IAP） | 從 Email 自動補全公司資訊 | 商機表單 Enrich 按鈕 |
| Lead Mining（IAP） | 從 Odoo 30 萬筆資料庫主動挖掘潛在客戶 | CRM → Pipeline → Generate Leads |
| Partner Autocomplete（IAP） | 建立聯絡人時自動帶入公司資料 | Contacts → New → 輸入公司名 |
| Email 信箱外掛 | Gmail / Outlook 直接從信箱建立商機或任務 | Gmail / Outlook 安裝 Odoo Add-in |
| 報表分析 | Pipeline 報表、活動報表、銷售團隊績效、行銷歸因 | CRM → Reporting |
| 遊戲化（Gamification） | 設定銷售目標挑戰、排行榜、徽章獎勵 | Settings → Gamification Tools |

## 三、業務流程位置

```
[潛在客戶接觸]
      ↓
  [Lead 建立]  ← 來源：業務手動、網站表單、活動報名、預約、網站訪客、Lead Mining
      ↓
  [Lead 轉換]  → Convert to Opportunity（可合併現有商機）
      ↓
[Opportunity 推進]  ← CRM Pipeline 主要管理範圍
  New → Qualified → Proposition → Won
                                 ↓ Lost（記錄原因，可還原）
      ↓（Won）
  [轉報價單]  → Sales 模組 [[../Sales/01_功能概覽|Sales 功能概覽]]
      ↓
  [轉訂單 → 出貨 → 開立發票]
```

**CRM 模組主要負責**：Lead 建立 → Opportunity 跟進 → Won/Lost 記錄

## 四、與其他模組的關係

| 相關模組 | 關係說明 |
|---------|---------|
| Sales | CRM 商機 Won 後可直接轉為銷售報價單 [[../Sales/04_內控點與風險\|Sales 內控點]] |
| Contacts | 客戶 / 聯絡人資料雙向共用；Partner Autocomplete 補全資訊 |
| Calendar | 活動排程與 Odoo Calendar 雙向同步，支援 Google / Outlook 同步 |
| Website | 網站表單、線上預約整合 Lead 生成 |
| Events | 活動報名自動觸發 Lead 生成規則 |
| Email（Mail Plugin） | Gmail / Outlook 外掛直接記錄通訊與建立商機 |
| Accounting | 銷售團隊 Invoicing Target 與 Accounting 發票連動 |
| Marketing Automation | UTM 追蹤 + CRM 行銷歸因報表 |

## 五、IAP 付費功能整理

以下功能需要 Odoo IAP Credits（額外費用），顧問需提醒客戶：

| 功能 | 計費單位 | 說明 |
|------|---------|------|
| Partner Autocomplete | 1 credit / 次 | 自動補全公司聯絡資訊 |
| Lead Enrichment | 按使用量 | 從 Email 補全公司資訊 |
| Lead Mining | 按使用量 | 主動挖掘潛在客戶 |
| Visits to Leads | 1 credit / 訪客 | 網站訪客轉 Lead |
