# Odoo Website & eCommerce 模組 - 欄位與單據清單

> 模組：Website + eCommerce
> 版本標示：Odoo（依影片介面推測，待確認）
> 學習日期：2026-07-30
> 狀態：草稿
> 資料來源：26 支官方教學影片（ECM01–ECM26）

---

## 一、商品（Product）相關欄位

### 1-1 基本資訊（General Information 分頁）

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Product Name | 文字 | 商品名稱，顯示於網站與訂單 |
| Product Type | 選項 | Goods（實體商品，可追蹤庫存）/ Service |
| Sales Price | 金額 | 銷售單價（不含稅） |
| Taxes | 多選 | 適用稅率（如 21% VAT） |
| Internal Reference | 文字 | 內部貨號/SKU |
| Acquisition Cost | 金額 | 採購成本（影響成本報告） |
| Purchase Taxes | 多選 | 採購適用稅率 |
| Track Inventory | 布林值 | 啟用後方可追蹤庫存數量 |
| Quantity on Hand | 數字 | 現有庫存數量（點選後可手動更新） |

### 1-2 eCommerce 分頁

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Published | 布林值/切換開關 | 是否在網站上發布（顧客可見） |
| Website Published (Category) | 布林值 | 分類頁面是否顯示此商品 |
| Description | 富文字 | 商品頁面顯示的詳細描述 |
| eCommerce Categories | 多選 | 所屬電商分類（可多選） |
| Tags | 多選 | 商品標籤（供搜尋/過濾使用） |
| Extra Media | 附件 | 額外圖片或影片（YouTube/Vimeo/DailyMotion/Facebook/Instagram） |
| Selling Options - Continue Selling | 布林值 | 缺貨時是否繼續允許購買 |
| Selling Options - Out of Stock Message | 文字 | 缺貨時顯示給顧客的訊息 |
| Selling Options - Display Available Qty | 布林值 | 庫存低於 5 件時顯示剩餘數量 |

### 1-3 Sales 分頁（銷售策略）

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Optional Products | 多對多 | 加入購物車時推薦的可選搭配商品 |
| Accessory Products | 多對多 | 購物車確認頁面推薦的配件商品 |
| Alternative Products | 多對多 | 商品頁面下方顯示的升級替代商品（upsell） |

### 1-4 Prices 分頁

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Sales Price | 金額 | 此分頁可依價格表設定不同定價 |
| Price Lists | 多選 | 可針對不同 Price List 設定對應售價 |
| Compared to Price | 金額 | 比較原價（設定後商品頁顯示刪除線原價） |

### 1-5 Inventory 分頁（物流設定）

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Weight | 數字（公斤） | 商品重量（影響依重量計費的配送規則） |
| Volume | 數字（立方公尺） | 商品體積（影響依體積計費的配送規則） |

### 1-6 Attributes & Variants 分頁

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| Attribute | 多對多 | 屬性名稱（如 Color、Size） |
| Values | 多選 | 屬性值（如 Red、Blue、S、M、L） |
| Sales Price Extra | 金額 | 此屬性組合的額外加價 |
| Exclude For | 多對多 | 排除此屬性值與特定其他屬性值的組合 |

## 二、網站設定相關欄位（Website Settings）

| 欄位名稱 | 位置 | 說明 |
|---------|------|------|
| Website Name | Settings → General | 顯示於瀏覽器標籤與網站標題 |
| Favicon | Settings → General | 瀏覽器分頁圖示（.ico/.png，32×32） |
| Website Domain | Settings → General（或建立網站時） | 網站域名（如 example.com） |
| Languages | Settings → Languages | 已啟用的網站語言清單 |
| Default Language | Settings → Languages | 預設語言（編輯模式使用的語言） |
| Sign in/up at Checkout | Settings → Customers | 結帳時的帳號政策（Optional/Disabled/Mandatory） |
| Automatic Invoice | Settings → Invoicing | 付款確認後自動產生並發送發票 |
| Cookie Bar | Settings → Privacy | 啟用 Cookie 同意欄 |
| Robots.txt | Settings → SEO | 搜尋引擎爬蟲存取規則 |
| Google Search Console | Settings → SEO | Google Search Console 驗證碼 |

## 三、電商設定欄位（eCommerce Configuration）

### 3-1 商品目錄設定

| 欄位名稱 | 位置 | 說明 |
|---------|------|------|
| Add to Cart Action | Settings → Cart | 加入購物車後的動作（停留/前往購物車） |
| Hide Add to Cart Button | Settings → Products | 特定分類顯示「聯絡我們」而非購物車按鈕 |
| Price List | Settings → Pricing | 啟用 Price Lists 功能 |
| Tax Display | Settings → Pricing | 商品價格含稅或未稅顯示 |
| Comparison Price | Settings → Pricing | 啟用比較原價刪除線功能 |
| Discounts, Loyalty & Gift Cards | Settings → Promotions | 啟用促銷/忠誠/禮品卡程式 |
| Automate Suggested Products | Settings → Products | 自動依購買紀錄推薦 Optional/Accessory/Alternative 商品 |
| Order Assignment - Sales Team | Settings → Orders | 新訂單指派的銷售團隊 |
| Order Assignment - Salesperson | Settings → Orders | 新訂單指派的銷售人員 |
| Order Confirmation Email Template | Settings → Orders | 訂單確認 Email 使用的範本 |
| Follow-up Abandoned Cart | Settings → Orders | 棄單追蹤 Email 啟用與時間設定 |
| Automatic Invoice | Settings → Invoicing | 自動開立並發送發票 |

### 3-2 Price List 欄位

| 欄位名稱 | 說明 |
|---------|------|
| Name | 價格表名稱（如 EUR、GBP、VIP） |
| Currency | 適用幣別 |
| Country Groups | 自動套用至特定國家的顧客（可空白表示手動選擇） |
| Selectable | 是否允許顧客在網站自行選擇此價格表 |
| Website | 適用網站（多網站時限制） |
| e-Commerce Promotional Code | 輸入代碼可啟用此價格表（用於促銷代碼） |
| Rules | 定價規則（依商品/分類/數量設定折扣方式） |

### 3-3 屬性（Attribute）欄位

| 欄位名稱 | 說明 |
|---------|------|
| Name | 屬性名稱（如 Color、Size、Material） |
| Category | 屬性分類（用於比較頁面分組） |
| Display Type | 商品設定頁面中的顯示方式（Pills/Color/Radio/Image/Select） |
| Variant Creation | 變體產生時機（Instantly/Dynamically/Never） |
| eCommerce Visibility | 是否在網站過濾器中顯示此屬性 |
| Show on Product Cards | 是否在商品卡片上直接顯示可選屬性 |
| Show Thumbnails | 是否以變體圖片取代顏色方塊顯示 |

### 3-4 Attribute Values 欄位

| 欄位名稱 | 說明 |
|---------|------|
| Value | 屬性值名稱（如 Red、Large） |
| Color Code | 顏色的 RGB 或 Hex 代碼（僅 Color 顯示類型適用） |
| Image | 代表此屬性值的圖片（紋理/花樣等） |
| Default Extra Price | 此屬性值的預設額外加價 |

## 四、訂單欄位

### 4-1 電商訂單（Sales Order）主要欄位

| 欄位名稱 | 說明 |
|---------|------|
| Order Status | 訂單階段：Quotation / Quotation Sent / Sales Order |
| Customer | 購買顧客（已登入帳號或訪客資訊） |
| Order Date | 訂單成立日期 |
| Sales Team | 負責銷售團隊 |
| Salesperson | 負責業務人員 |
| Order Lines | 訂購商品明細（商品/數量/單價/小計） |
| Delivery Method | 選擇的配送方式 |
| Payment Method | 使用的付款方式 |
| Source | 訂單來源（如 Website） |
| Billing Address | 帳單地址 |
| Shipping Address | 配送地址 |
| Company Name | 公司名稱（B2B 欄位啟用時顯示） |
| Gift Message | 禮品留言（Extra Step 自訂欄位） |
| Invoice | 連結的發票（Invoice 智慧按鈕） |
| Delivery | 連結的出貨單（Delivery 智慧按鈕） |

### 4-2 訂單三個主要階段說明

| 階段 | 觸發時機 | 代表意義 |
|------|---------|---------|
| Quotation（詢價單） | 商品加入購物車但未完成結帳 | 潛在棄單，可發送追蹤 Email |
| Quotation Sent（已傳送詢價單） | 完成結帳流程但付款尚未確認 | 如選擇銀行轉帳、Click & Collect 等需人工確認的付款方式 |
| Sales Order（銷售訂單） | 付款已確認 | 正式訂單，可安排出貨、開立發票 |

## 五、顧客帳戶相關欄位

### 5-1 顧客 Portal 帳戶設定

| 欄位名稱 | 位置 | 說明 |
|---------|------|------|
| Portal Access | eCommerce → Customers → 顧客記錄 → Action → Grant Portal Access | 控制顧客是否可登入 Portal |
| Portal Access Status | 同上 | Active（已啟用）/ Not Granted（未授予） |

### 5-2 顧客 Portal 頁面顯示內容

| 區塊 | 說明 |
|------|------|
| Orders | 歷史訂單清單（可點選查看詳情） |
| Invoices | 待付/已付發票清單 |
| Addresses | 儲存的送貨/帳單地址 |
| Payment Methods | 儲存的付款方式（信用卡等，需供應商支援） |
| Appointments | 預約紀錄（若安裝 Appointment 模組） |
| Loyalty Points | 積點餘額（若啟用忠誠計劃） |
| eWallet Balance | eWallet 餘額（若啟用 eWallet） |
| Gift Cards | 禮品卡代碼與餘額 |

### 5-3 忠誠計劃（Loyalty Program）欄位

| 欄位名稱 | 說明 |
|---------|------|
| Program Name | 計劃名稱（如 Glazed Loyalty） |
| Program Type | 類型：Loyalty Card / Next Order Coupon / Coupon / Buy X Get Y / Promotional Program |
| Start Date / End Date | 有效期間（End Date 空白 = 永不過期） |
| Limit Usage | 是否限制每位顧客使用次數 |
| Currency / Price List | 限制適用幣別或價格表 |
| Available On | 可用平台：Sales / Website / Point of Sale |
| Points Name | 積點名稱（預設 Loyalty Points，可自訂如 Glazed Points） |
| Rules（條件） | 觸發積點的條件：最少購買件數、最少消費金額、每歐元積點數 |
| Rewards（獎勵） | 積點可換取的獎勵：免費商品 / 折扣（%或固定金額）/ 免費配送 |
| Points Cost | 每次兌換獎勵所需積點數 |

### 5-4 禮品卡（Gift Card）欄位

| 欄位名稱 | 說明 |
|---------|------|
| Program Name | 禮品卡計劃名稱 |
| Linked Product | 關聯商品（需在 eCommerce 發布，顧客購買此商品即購買禮品卡） |
| Email Template | 顧客購買後收到的 Email 範本 |
| Anonymous / Selected Customers | 是否限制特定顧客使用 |
| Quantity | 生成的禮品卡數量（即可供購買數量） |
| Value | 每張禮品卡的面額 |
| Validity | 有效期限（空白 = 永不過期） |
| Description | 禮品卡說明文字（附於 Email） |
